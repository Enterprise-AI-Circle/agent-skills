## Warum Jekyll hier?

Für GitHub Pages ist Jekyll der native Weg. Das Eleventy-Repo bleibt unverändert; dieser Unterordner zeigt, wie das gleiche Look-and-Feel mit Liquid statt Nunjucks aussehen kann.

## Gemeinsamkeiten

1. Markdown als Content-Quelle
2. Layouts und Includes für wiederverwendbare Shell
3. Statischer Build ohne Server-Runtime

## Unterschiede

| Aspekt | Eleventy (Hauptrepo) | Jekyll (Dummy) |
|--------|----------------------|----------------|
| Templates | Nunjucks | Liquid |
| Macros | `blocks.njk` | Includes / HTML |
| Hosting | Vercel | GitHub Pages |
